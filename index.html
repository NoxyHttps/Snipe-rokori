Dudas

Preguntas frecuentes

¿Dónde quedan mis cookies?

En el localStorage de tu navegador. Cada request las manda al proxy de Vercel, que las usa para firmar contra rokori y no las guarda.

¿Por qué el login HTTP puede fallar?

rokori protege el login con Cloudflare Turnstile. El POST directo no resuelve el reto, así que el camino confiable es correr el script de login y subir el cookies.json.

¿La compra gasta Robux de verdad?

Sí, si estás en modo auto y sin dry run. En "solo avisar" nunca compra.

¿Se cae si cierro la pestaña?

Sí, el motor vive en la pestaña. Dejala abierta; el estado queda guardado para retomar.
